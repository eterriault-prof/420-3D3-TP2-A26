# TP2 — Catalogue GameNeuve

Catalogue de produits numériques du studio fictif **GameNeuve**, implémenté avec Flask.

## Prérequis

- Python 3.10+/
- Flask

Dans un environnement virtuel, installer Flask avec la commande suivante :
```bash
pip install flask
```

## Démarrage

```bash
python app.py
```

Le site est ensuite accessible à l'adresse : [http://localhost:5000](http://localhost:5000)

## Structure du projet

```
app.py              ← application Flask (ne pas modifier)
catalogue.py        ← logique du catalogue
models.py           ← modèles de données
templates/          ← gabarits HTML (ne pas modifier)
static/             ← feuilles de style (ne pas modifier)
data/catalogue.json ← données du catalogue (ne pas modifier)
```
